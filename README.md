# Hermes Telegram Bot

Учебный проект Telegram-ассистента на базе **Hermes Agent** с моделью **DeepSeek**. Пользователь пишет боту в Telegram, Hermes обрабатывает запрос через DeepSeek API и возвращает ответ в чат.

Этот репозиторий содержит конфигурацию развёртывания, шаблон переменных окружения и PowerShell-скрипты запуска. Движок бота — сторонний открытый проект [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent); его исходники и зависимости устанавливаются отдельно. Репозиторий не выдаёт движок Hermes за собственную разработку.

## Возможности

- Общение с ассистентом на естественном языке в Telegram.
- Ответы, объяснения, помощь с текстами и задачами через DeepSeek.
- Доступ только для перечисленных владельцем Telegram-пользователей.
- Локальное хранение настроек и истории вне Git.

Схема работы: `Telegram → Hermes gateway → DeepSeek API → ответ в Telegram`.

## Требования

- Windows и PowerShell 5.1 или новее; Git.
- Установленный Hermes Agent и команда `hermes` в PATH.
- Токен Telegram-бота от [BotFather](https://t.me/BotFather).
- Ключ DeepSeek API с доступным балансом и доступом к выбранной модели.
- Интернет, доступ к Telegram и DeepSeek.

Настройки подготовлены для Hermes Agent 0.21.0 и модели `deepseek-v4-pro`, использовавшихся в локальной установке. Доступность модели зависит от провайдера; её можно изменить в `.hermes/config.yaml`.

## Установка

1. Установите Hermes по [официальной инструкции](https://github.com/NousResearch/hermes-agent#installation). Для Windows официальный установщик запускается в PowerShell:

   ```powershell
   irm https://hermes-agent.nousresearch.com/install.ps1 | iex
   ```

   Откройте новое окно PowerShell после установки.

2. Склонируйте этот репозиторий и перейдите в его папку:

   ```powershell
   git clone https://github.com/dkolesnikov-a11y/hermes-telegram-bot.git
   cd hermes-telegram-bot
   powershell -NoProfile -File ./scripts/setup.ps1
   ```

3. Откройте `.hermes/.env` локально и заполните:

   - `TELEGRAM_BOT_TOKEN` — токен вашего бота.
   - `DEEPSEEK_API_KEY` — ваш ключ DeepSeek.
   - `TELEGRAM_ALLOWED_USERS` — ваш числовой Telegram user ID, не username и не ID бота. Несколько ID разделяются запятыми.
   - Оставьте `TELEGRAM_ALLOW_ALL_USERS=false`.

   Узнать свой ID можно командой `/whoami` в настроенном Hermes-боте. Не публикуйте заполненный файл.

## Запуск и проверка

Если этот же Telegram-бот уже работает в другой установке Hermes, сначала остановите прежний gateway там: два процесса с одним токеном конфликтуют при получении сообщений. Скрипты проекта не переносят и не останавливают существующую установку автоматически.

```powershell
powershell -NoProfile -File ./scripts/start.ps1
```

Скрипт использует отдельную папку `.hermes` внутри проекта через `HERMES_HOME`. Запуск идёт в текущем окне, остановка — `Ctrl+C`. Для работы бота компьютер должен оставаться включённым; автозапуск этим проектом не устанавливается.

Откройте своего бота в Telegram, нажмите «Запустить» и отправьте «Привет! Что ты умеешь?». Убедитесь, что пришёл ответ. Если ответа нет, проверьте заполнение `.env`, баланс DeepSeek, доступность сети и отсутствие второго gateway с тем же токеном. При необходимости задайте `TELEGRAM_PROXY` в локальном `.env`.

Если PowerShell блокирует скрипты, для этого окна можно использовать `Set-ExecutionPolicy -Scope Process RemoteSigned`, если это разрешено правилами вашего компьютера.

## Безопасность публикации

В Git не должны попадать `.env`, `.hermes/`, ключи, пароли, логи, история переписки, базы данных и зависимости. Шаблоны содержат только пустые поля и общедоступные настройки. Не помещайте личные данные в README и другие отслеживаемые файлы: `.gitignore` исключает пути, но не распознаёт секреты внутри текста.

Перед публикацией проверяйте `git status` и `git diff --cached`. Если секрет уже был закоммичен, одного добавления в `.gitignore` недостаточно: отзовите ключ у провайдера, замените его локально и очистите историю Git перед дальнейшей публикацией.

## Статус проверки

В исходной локальной установке подтверждена обработка Telegram-сообщения через Hermes и отправка ответа. Этот репозиторий публикует воспроизводимые настройки и скрипты, но не содержит рабочие ключи. Запуск из свежего клона требует ваших ключей и отдельной проверки по инструкции выше.
