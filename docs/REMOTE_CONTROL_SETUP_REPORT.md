# Отчёт: настройка Remote Control через Telegram

**Дата:** 15 сентября 2026 года  
**Тип работы:** установка и настройка готового решения с открытым исходным кодом.

## 1. Цель задания

Настроить Telegram-бота, которому можно отправлять запросы обычным текстом для разработки проектов и выполнения команд на своём компьютере. Предусмотреть дальнейшее управление собственным сервером через SSH.

## 2. Выбранное решение

Использован сторонний проект [artickc/codex-telegram-bot](https://github.com/artickc/codex-telegram-bot), версия **1.1.1**, лицензия MIT. Проверенный коммит: `e084c58ee5d358f80cdde4d982b13b144b035421`.

Бот связывает Telegram с установленным Codex CLI через протокол **Codex app-server**. Это готовый открытый проект, а выполненная работа — его развёртывание, настройка доступа и адаптация подключения к сети.

Этот отчёт размещён рядом с учебным проектом Hermes. Установка Remote Control использует отдельного бота и Codex; существующая установка Hermes не изменялась.

## 3. Схема работы

```text
Пользователь в Telegram
          ↓
Проверка разрешённого Telegram user ID
          ↓
Telegram-мост на компьютере Windows
          ↓
Codex app-server
          ↓
Рабочая папка: файлы, код, команды
          ↓
Результат в Telegram
```

Для будущего подключения сервера: Codex → SSH → собственный сервер. Эта часть пока не настроена.

## 6. Пример конфигурации без секретов

Ниже приведён учебный шаблон. Значения в угловых скобках требуется заменить локально; шаблон не является готовой рабочей конфигурацией.

```dotenv
TELEGRAM_BOT_TOKEN=<BOT_TOKEN>
ALLOWED_USERS=<OWNER_TELEGRAM_USER_ID>
CODEX_CLI_PATH=<PATH_TO_CODEX>
CODEX_WORKSPACE=<PROJECTS_DIRECTORY>
PROJECT_ROOTS=<PROJECTS_DIRECTORY>
CODEX_TRUST_ALL_TOOLS=false
TELEGRAM_PROXY_URL=<LOCAL_HTTP_PROXY_URL>
AUTO_UPDATE=false
NOTIFY_OTHER_SESSIONS=false
LOG_LEVEL=info
```

Настоящие значения хранятся только в локальном файле `.env`. В этот отчёт не включены токены, личные ID, имена аккаунтов, адреса серверов, локальные пути пользователя или настройки доступа.

## 8. Использование

1. Открыть своего бота в Telegram и нажать **Start**.
2. Выполнить `/projects` и выбрать рабочий проект.
3. Отправить задачу обычным текстом, например: «Создай простой сайт со списком задач».
4. При запросе расширенных прав проверить действие и подтвердить или отклонить его.
5. Использовать `/status` для просмотра состояния, `/sessions` для продолжения сессии и `/cancel` для остановки задачи.

Для работы компьютер и используемый прокси должны оставаться включёнными.

До публикации выполнена проверка текста на известные локальные значения и типичные форматы секретов. Это проверка публикуемого отчёта, а не аудит всей истории существующего репозитория.
